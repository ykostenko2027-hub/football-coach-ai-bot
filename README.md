# Кишеньковий футбольний тренер та експерт (Pocket Football Coach)

Telegram-бот зі штучним інтелектом для футболістів-аматорів: генерація персональних тренувань під наявний інвентар, розбір правил IFAB та налаштування на гру.

Проєкт у межах курсу «Розробка застосунків зі штучним інтелектом».

---

## 📂 Структура проєкту

* [`docs/passport.md`](docs/passport.md) — паспорт проєкту (постановка задачі, межі, критерії якості, вибір моделі, ризики).
* [`docs/backlog.md`](docs/backlog.md) — план реалізації за етапами ПР14–ПР20.
* [`eval/cases.json`](eval/cases.json) — початковий набір прикладів для оцінювання (normal, edge, negative, adversarial).
